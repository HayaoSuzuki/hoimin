# 送料計算の仕様

本教材の正本は教科書の「実習仕様」。このファイルは実習フォルダだけでも調査できるよう同じ規則を収録する。

`shipping_fee(subtotal: int, weight: int, *, member: bool, remote: bool) -> int`

- 金額は円、重量はgの整数。入力の型が正しいことは呼び出し側の責任とする。
- 商品合計額または重量が負なら、空注文の判定より先に `ValueError` を送出する。メッセージの文言は指定しない。
- 商品合計額と重量が両方0なら空注文。会員、遠隔地の指定によらず0円。
- 片方だけ0なら通常注文。
- 通常注文は基本送料500円。
- 重量が2000gを超えると300円を加算。2000gちょうどでは加算しない。
- 会員には200円の割引。割引後の下限は0円。
- 商品合計額5000円以上なら、ここまでの送料を0円にする。
- 最後に、遠隔地なら400円を加算。5000円以上の注文にも適用する。
- 内部の変数、式、条件文の構成は指定しない。

例: `shipping_fee(1000, 3000, member=True, remote=True) == 1000`

例: `shipping_fee(5000, 3000, member=True, remote=True) == 400`
