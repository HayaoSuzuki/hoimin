# 実習仕様

送料を円単位の整数で返す関数 `shipping_fee` を対象とする。
これは学習用に定めた架空の料金制度であり、実在の配送サービスの料金ではない。

```python
shipping_fee(subtotal: int, weight: int, *, member: bool, remote: bool) -> int
```

`subtotal` は商品合計額（円）、`weight` は荷物の重量（g）である。
`member` は会員かどうか、`remote` は遠隔地への配送かどうかを表す。
入力の型は呼び出し側が満たす前提とし、文字列や浮動小数点数、真偽値を金額として渡した場合の扱いは、この仕様の対象外とする。

## 入力と空注文

商品合計額または重量が負なら `ValueError` を送出する。
例外メッセージの文言は指定しない。
この検証は、空注文の判定よりも先に行う。

商品合計額と重量が**両方とも0**なら空注文とし、会員区分や配送先によらず送料は0円とする。
片方だけが0の注文は空注文ではなく、通常の料金規則を適用する。
無料の商品や重量を整数gに丸めた荷物を想定した、教材上の規則である。

## 通常注文の料金

料金計算には次の順序を適用する。

1. 基本送料を500円とする。
2. 重量が2000gを超える場合、300円を加算する。2000gちょうどでは加算しない。
3. 会員には200円の割引を適用する。割引後の金額の下限は0円とする。
4. 商品合計額が5000円以上なら、ここまでの送料を0円とする。5000円ちょうどを含む。
5. 遠隔地への配送には400円を加算する。この加算は5000円以上の注文にも適用する。

たとえば、商品合計額1000円、重量3000g、会員、遠隔地なら、`500 + 300 - 200 + 400 = 1000` 円である。
商品合計額5000円で同じ条件なら、通常送料は無料になるが遠隔地加算は残るため400円である。

## 仕様に含まれない観測

中間変数の名前、条件文の並び方、関数内部で使う式は指定しない。
有効な入力について返す金額と、不正な負数入力について送出する例外型を観測対象とする。
実装から計算した値をそのまま期待値にせず、この料金規則から期待値を導く。
