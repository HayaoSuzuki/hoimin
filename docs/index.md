# Documentation

Choose documentation by audience:

- [User documentation](user/index.md): installation, usage, CLI and compatibility references, support and licensing.
- [Development documentation](development/index.md): contributor procedures, architecture, current knowledge and development records.

Current guides explain supported behavior and maintained procedures. Dated plans,
reviews and measurements belong in [development records](development/work/index.md).
See the [documentation policy](development/guides/documentation.md#where-documents-belong)
when adding or moving a document.
