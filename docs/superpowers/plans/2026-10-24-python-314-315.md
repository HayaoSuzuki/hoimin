# Python 3.14・3.15対応 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan in the dedicated worktree.

**Goal:** 同じ配布wheelをPython 3.14・3.15でインストール・実行できるようにする。
**Architecture:** Rust CLIと既存パーサーを維持し、配布メタデータ・検証用Python・CIを更新する。wheelは一度ビルドして両版で検証する。
**Tech Stack:** Rust、uv、Maturin、pytest、GitHub Actions。
**Spec:** `docs/superpowers/specs/2026-10-24-python-314-315-design.md`

## Global Constraints

- Requires-Python: `>=3.14,<3.16`。3.12・3.13と3.16は対象外。
- Ruff・tyと共通コードの基準: Python 3.14。
- 3.15新構文や新演算子は追加しない。
- 各段階でセルフレビューを最低5回実施し、結果をレポートへ記録する。
- メモリ・ディスクを確認し、不要なビルド成果物をworktree内で整理する。

## Review Focus

- uvxが3.14に固定され、3.15のwheel確認が実際には実行されない。
- frozen lockfileとRequires-Pythonが一致しない。
- 複数のRust CI jobが同名のartifactをアップロードする。
- リリースの3.15 smokeの失敗が公開前の必須チェックに含まれない。
- 共通コードや型検査が3.15専用になり3.14で動かなくなる。
