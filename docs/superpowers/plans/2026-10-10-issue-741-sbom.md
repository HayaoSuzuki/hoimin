# Issue #741 SBOM Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. The user requests completion on the current branch and five self-reviews per stage.

**Goal:** 配布物に対応した6 SBOMを検証して公開アセットへ追加する。
**Architecture:** 同じbuild環境でraw graphを取得し、ホスト上で補完・検証する。全アセットの検証後にchecksumを生成する。
**Tech Stack:** cargo-cyclonedx 0.5.7, CycloneDX 1.5, Python/jsonschema 4.25.1, Hypothesis, Lean.
**Spec:** ../specs/2026-10-10-issue-741-sbom-design.md

## Global Constraints

現在の `add-sbom` ブランチを使用する。外部公開しない。6 SBOM、--no-default-features、target別、lockfile不変、dev/fuzz依存除外、既存公開保護維持。

## Review Focus

- schema-validでもversion/commit/platformが違う入力を拒否する。
- graphの参照欠落・重複・未到達componentを拒否する。
- Linux wheelのgraphをhostで代用しない。
- 既存SHA256SUMSがある再実行で失敗しても公開しない。
- PyPIは追加SBOMをwheelとして扱わない。
