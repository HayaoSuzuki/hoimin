## Global constraints

Adopted operators default on with opt-out. No new dependencies, target execution during analysis, compatibility machinery or test-framework assumptions. Two Cargo jobs, no incremental compilation/debug symbols. Preserve private untracked files. Include docs and audit evidence in the PR. At least five actual self-review passes per stage.

## Review focus

1. Shadowed builtins/imports must not be mistaken for known APIs.
2. Function/class/comprehension boundaries must not leak eligibility.
3. Generated edits must preserve valid syntax, grouping, comments and UTF-8 offsets.
4. Bounded synthetic evidence must not be presented as real-project efficacy.
5. All new defaults must honor exclusions, selectors, candidate caps and cancellation.
