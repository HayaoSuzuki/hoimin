# Issue 873: typed source decoding failure classification

For maintainers: classify source-encoding failures structurally while preserving
meaningful candidate-validation precedence and source safety.

Baseline: main 49a34a63ac4e995bfefb156f85ff3a934b594e6b.
Branch: codex/issue-873-typed-encoding.

## Final design and compatibility

SourceEncodingError is one public enum with ImplicitUtf8 and Encoding variants,
each retaining encoding/reason diagnostic data. The public decoder returns it
directly. CandidateValidationContext stores that same type, decoded_source
borrows it directly, and candidate validation matches its variant.
Mutation-text encoding failures use Encoding.

The user clarified that structural simplicity takes priority over basic
backward compatibility and that regenerating saved plans is acceptable.
Accordingly, the initial private wrapper and public diagnostic projection were
removed rather than retaining the old Rust struct shape. SourceEncodingError
construction and field access are a Rust API change: callers construct or
match the appropriate variant instead of using struct fields directly.
Display diagnostics, CLI behavior, source codecs, byte spans, candidate IDs,
saved-plan/report/store schemas and the 0.5 version floor are unchanged.
No saved-plan migration is introduced or required by this representation change.
Internal Rust APIs have no independent compatibility guarantee under
docs/compatibility.md.

## Design review passes

1. Traced decoder failures and candidate validation: the implicit UTF-8 display
   label is presentation data and must never select the candidate error variant.
2. Compared implicit and declared UTF-8 inputs. Both can reject identical bytes,
   but their meaningful classifications remain distinct.
3. Audited actual callers: decoder consumers format errors or use successful
   values; mutation encode constructs errors inside source_encoding.rs.
   Candidate validation is the classification consumer.
4. Chose one public typed error instead of the initial private failure wrapper,
   two projection methods, and second decoder entry point. This removes
   compatibility-only transport without adding a framework.
5. Checked codec sharing: Encoding describes declared decoding and mutation-text
   encoding failures, while ImplicitUtf8 applies only to undeclared source.
   Diagnostic spelling remains independent of the variant.
