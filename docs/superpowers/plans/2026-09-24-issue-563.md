# Issue 563 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Reject reuse of results generated under different copy patterns.

**Architecture:** Carry ordered include/exclude lists from RunConfig into two new fingerprint fields. Advance the fingerprint schema without changing session storage.

**Tech Stack:** Rust, existing blake3 encoder, SQLite session integration tests.

**Spec:** ../specs/2026-09-24-issue-563-design.md

## Global Constraints

- Rust 1.88 minimum; no new dependencies.
- Preserve glob order, spelling and include/exclude separation.
- Preserve operational jobs/max-output compatibility.

## Review Focus

- Both adding and removing patterns must invalidate results: CLI matrix.
- Explicit fingerprint-file cannot substitute for copy policy: flag remains fingerprinted.
- Ordered negations must not be sorted: core order test.
- An unchanged policy must reuse the same incomplete run: CLI control.
- Old session fingerprints must remain distinct: version assertion and documented transition.
