# Issue #923: required fields in saved normalized configuration

Authorized scope: remove omission defaults for `RunConfig.import_roots` and
`PlanConfig.fingerprint_files`. Missing and null values must fail decoding;
explicit empty and nonempty arrays remain valid. Raw CLI defaults, optional
fields, fingerprint bytes, selection and opaque progress configuration stay as
specified. No compatibility adapter, conversion or Lean model is needed.

Base: `7c3a9105c432ec1e0ba2483ada42b10133d071a6` in the isolated
`fix/issue-923-required-saved-config` worktree. On 2026-10-16, GitHub release
inspection returned v0.8.12 as latest; the new minimum is 0.9.0.
