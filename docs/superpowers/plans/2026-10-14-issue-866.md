# Analyzer handler session contract (#866)

Base: `906ba668de94115ef5ca459af3b5f176d22b1b4e` (main).
Branch: `codex/issue-866-analyzer-contract`.

## Design

This reference is for Rust callers and maintainers who need to decide whether
candidates survive a request and who owns their files. Add the English contract
at the analyzer module entrance, with a short `AnalyzerHandler`/`handle` entry
point and links from the development guide and existing analyzer OKF concept.
Preserve executable source, tests, configuration, and saved formats.

### Design self-reviews

1. **Session identity:** traced `handle_with_cancellation` and `analyze_and_store`.
   The retained store, not the handler's entire lifetime, defines accumulation.
   Corrected the design to say a post-finalization call begins a fresh sequence.
2. **Limits:** compared first-store creation, remaining-budget subtraction, and
   `CandidateStore::push`. The store retains the first limit while analysis uses
   the request's limit. Added a consistency precondition instead of claiming
   later requests resize the store or configuration changes are rejected.
3. **Completion:** compared the final-target/truncated branch with the multiple
   request and non-final truncation integration tests. Included early finalization
   on truncation and per-request diagnostics; `spool: None` does not mean no work.
4. **Failure boundary:** followed source reading before `take`, source decoding
   after `take`, join errors, and the early cancellation branches. Split retained
   accumulation from lost accumulation rather than promise generic retry safety.
5. **Ownership:** compared `NamedTempFile`, `finish().keep()`, the cloned worker
   owner, and shell release/cleanup. Added the abandoned successful worker case:
   a detached worker can persist a spool whose reference is never delivered.
   Kept process drain semantics out of this contract.

## Implementation self-reviews

1. **Public entry points:** reviewed the module contract cold against `handle`.
   Added short struct and method references so a caller can find the session
   contract without searching private helpers. Kept the existing error list.
2. **Interruption positions:** reread the biased selects and propagation operators.
   Distinguished source-read errors from decoding/analysis errors and store
   creation failure from a retained initialized store. No rollback guarantee.
3. **Detached lifetime:** inspected the worker closure, join selection, and owner
   clone. Dropped waiters cannot restore the taken store. Explicit cancellation
   can return before worker exit; directory ownership lasts independently.
4. **Final spool cleanup:** reread `CandidateStore::finish` and shell release sites.
   Named the returned spool as a reference rather than an RAII guard. Explained
   standalone caller cleanup and managed-directory coordination separately.
