# Issue 902: typed review references

This implementation record helps maintainers review the artifact reference contract and reproduce verification. Scope is review annotation references; checked report readers and candidate indexes stay outside this change.

## Design

`ArtifactReference` owns a path and BLAKE3 content hash. `ReportReference` composes an `artifact: ArtifactReference` with a required `run_id: String`. `ReviewDraft.plan` uses the common reference and `report` remains optional. Nested composition preserves strict unknown-field rejection without serde flatten. Content validation remains at the existing draft boundary. Report run IDs reject blank strings, all control characters and values over 4096 UTF-8 bytes. Annotation reason/evidence limits remain unchanged.

Review JSON schema and SQLite user_version become 2. Version 1 stores are rejected on read and write without migration; old JSON plan run_id (including null), and missing/null report run_id are rejected. Persisted report references use `{artifact: {path, content_hash}, run_id}`. CLI arguments and human rendering keep their existing behavior.

### Five design self-review passes

1. Responsibility: inspected model.rs and input.rs; path/hash are shared, run identity is report-only. Selected two concrete types, with no phantom parameter or generic framework.
2. Construction: traced load_report and record_store; loaded report always supplies its own run ID. Preserve Option on the report, not on its ID.
3. Persistence: inspected strict serde structs and SQLite opening. Flat composition would complicate unknown-field rejection; corrected design to nested artifact and bump both versions.
4. Safety: inspected validate_draft; retain path/hash and bounded annotations. Found safe_text permits tabs/newlines; run IDs are identifiers, so prohibit all control characters while retaining annotation whitespace.
5. Scope: checked index and source observation contracts; neither requires changes. Rendering serializes nested drafts automatically; document output version change explicitly.
