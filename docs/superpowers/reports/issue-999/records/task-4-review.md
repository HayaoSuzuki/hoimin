#### Important (Should Fix)

1. **Valid additional preconditions bypass complete source-contract checking.** `tools/verify_creusot.py:154` recognizes only attributes starting with the normalized literals `#[cfg_attr(creusot,requires(` or `#[cfg_attr(creusot,ensures(`. Both passed `check_source_scope` in a focused temporary-source reproduction; the equivalent exact-spelling `cfg_attr(creusot, requires(...))` was rejected. The approved manifest and required postconditions can therefore remain unchanged while a new assumption excludes public inputs.

   The later generated guard does not close this gap: `tools/verify_creusot.py:242` checks ensures markers, not the actual precondition set. Adding ` /\ UInt64.t'int selected'0 < 100` to the requires conjunction in a temporary copy of real `project_top_budget.coma` still passed `check_generated_scope` with 25 files / 59 expected goals. Its unchanged report shape also passed `check_proof_status`. This was a parser sensitivity check, **not a solver run** against modified Coma. A stronger assumption can retain provable existing postconditions and named goals, and no later runner guard checks the reduced domain. Parse effective contract attributes, or explicitly reject unsupported contract-bearing attributes instead of ignoring them. Add focused cases for equivalent cfg predicates, qualified names and compound/nested attributes; the existing extra-contract test only uses the literal recognized spelling (`tests/test_verify_creusot.py:80`).

2. **SIGTERM leaves the command session alive.** `tools/verify_creusot.py:373` reaches `terminate_session` only through `TimeoutExpired` or Python exceptions. No SIGTERM handler is installed in `main` (`tools/verify_creusot.py:548`), and default SIGTERM termination does not raise a Python exception. In a focused host-POSIX reproduction, terminating a wrapper executing `run_command` produced exit `-15`, while its sleeping child in the new session remained live. The reproduction immediately killed only that owned child group. A normal termination request can thus bypass interruption cleanup and leave compiler/solver processes alive after the deadline controller exits. Install scoped termination handling that routes catchable shutdown signals through owned-session cleanup and returns failure, with a focused SIGTERM subprocess test. Preserve session ownership; SIGKILL is uncatchable and is not part of this requested fix. The reproduction ran on the POSIX host, not in a new Linux proof container; the missing handler is visible in the runner itself.
