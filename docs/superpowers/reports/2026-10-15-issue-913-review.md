## Implementation self-review (five passes)

1. Representation and reachability: reviewed every old field reference and each
   new enum constructor. Only attach creates Signalable in production; reap and
   probing preserve ProbeOnly or clear it. Attach retains its existing one-time
   lifecycle precondition. `terminated` and `tree_quiescent` remain separate.
2. Error ordering: compared termination line by line against the base. The
   terminated short circuit still precedes probes; disarm precedes a fallible
   probe; injected termination failure still follows probing and precedes signal.
   SIGKILL ESRCH succeeds, signal EPERM errors, probe EPERM means present.
3. Ownership and Drop: reviewed all fake-PGID tests. The RAII guard is declared
   before the supervisor, and the synthetic constructor asserts a fake is
   installed. Guards survive actual supervisor Drop and unwind. The older direct
   representation test removes its synthetic ID before dropping the supervisor.
4. Platform/API scope: inspected cfg boundaries and the complete diff. The enum,
   Unix kill wrapper and test module are Unix-only. No Windows job logic, Linux
   backend code, public signature, dependency, CLI or serialization changed.
5. Complexity and comments: state disarming/probing are owned by the enum; the
   syscall wrapper centralizes the existing unsafe operation and its errno read.
   The fake's storage and helpers live entirely in test code. Comments explain
   recycled identifier risk and absence evidence instead of restating variants.
   Scoped design score is 8.75/10: seven observable diagnostics pass; the
   design-time percentage was not measured. No observable row remains failed;
   the unmeasured metric does not justify more implementation.

transitions, while real-process integration covers the existing descendant

checks in new tests; the correction changes assertion diagnostics only.
