1. Enumerated every previous phase and transient Idle-with-candidate assignment. Ready now owns the loaded candidate; Idle/Reading hold none. Persisting/Finishing own one result whose candidate provides identity.
2. Inspected every complete state replacement and candidate projection. Removed the phase/Option synchronization invariant; retained worker/effect bounds and the meaningful Reading-phase precondition for candidate completion.
3. Compared every stop branch. Taking each enum recovers owned data and resets the worker atomically. Persisting contributes summary once; Finishing does not recount; synthetic start/finish classes and sorting remain unchanged.
4. Followed output acknowledgements through reset. Results remain owned while output is pending, then Resetting releases them because the workspace owns reset data. Retired/duplicate/wrong-worker/run/mutant checks remain in their original boundaries.
5. Reviewed error paths and allocation. A locally taken Persisting result is discarded only on an error return that exposes no mutated RunState. Shared effect/state consumers retain required clones; stopped recovery moves values instead of cloning fields and clearing them separately.
