# Issue 565 reviews and verification

## Design review 1: root cause

Read the original type-annotation contract and `contains_disallowed_annotation`.
Subscript recursion reaches its slice, but multi-argument slices are Tuple and
fall through to false. Existing tests concentrate on single-argument containers.
The design adds recursive tuple elements rather than blanket tuple rejection.

## Design review 2: consumers and scope

Read `annotation_replacements`, nullable add/remove, and collection replacements.
The common entry guard serves all seven type operators, not just nullable add.
Added per-operator positive/negative coverage. Name trust (#564), deferred
annotation scope, and arbitrary expression semantics are separate concerns.

## Design review 3: model boundary

Read the committed NullableGate model, generator, corpus, and CI registration.
The recursive theorem already covers unbounded tree depth, while finite broken
rule detection covers depths 0–2. Preserve those bounds; extend source fixtures
and add left-only sensitivity. Model/source correspondence remains executable
observation, not a theorem about Rust or Python's full type system.

## Plan review 1: acceptance mapping

nesting/aliases with clean controls, all consumers, formal checks, and public CLI.
Added a third-position case to detect implementations that inspect only two
arguments. The source/replacement comparison uses corpus expectations directly.

## Plan review 2: existing corpus gaps

with repaired structural cases. No #564 fix or success claim is included.

## Plan review 3: reproducibility

The Lean module and generator are already registered in CI; extending them and
adding a normal Cargo integration test makes the new correspondence mandatory
without a parallel hand-maintained fixture set. Use the existing bounded Lean
guard, shared CPython interpreter, sequential reused Cargo target, 2 build jobs,
and RUST_TEST_THREADS=2. All six initial reviews precede product implementation.

Ruling: Proceed without another approval prompt as explicitly authorized. No
subagents or unrelated name-resolution changes are included in this worktree.

Design/plan boundary review amendment: CPython 3.14 evaluates tuple/list unpacking
in generic arguments, and accepts list-valued arguments. Direct Tuple recursion
alone would still miss `dict[*(str,Any)]`, `dict[*[str,Any]]`, and `list[[Any]]`.
Expand the structural rule to List elements and Starred.value, with clean and
blocked controls in both Rust and the Lean-generated corpus. This is a concrete
acceptance-boundary correction before any production edit.
