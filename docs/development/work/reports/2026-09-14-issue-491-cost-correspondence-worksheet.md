Lean defines cases once in PerformanceCostCases; PerformanceCostAuditMain emits performance-cost.jsonl. Native integers are checked before adapter execution. All source/counter cases below are **internal-fixture**: the source and operators are production inputs, but observation of private operation counters requires the test seam. The Lean algebra and finite witness proofs are **model-only**, not measurements. Release CLI measurements use public subprocesses and are kept in a separate report with binary digests and environment metadata.

0/1 and7/8/9 include degenerate and exact tree boundaries;8/16/32 provide N/2N/4N. The nested zero/one cases share a one-level minimum valid fixture and do not claim two distinct source sizes. Finite scan/clone/eager-byte search is0..32 and uses three binding effects, max32 events and max34 queries. Query positions include before the first event and after the last; duplicates retain insertion-order effects.

The scan control performs each full-history traversal and counts actual visits. Clone control calls actual KnownImports::clone inside record; eager control invokes actual replacement builders before the operator filter. All controls retain original semantic results and must fail the same bound predicates. They do not supply fabricated counters. Preflight sensitivity actually buffers all files for each worker and violates the same observed bound.

A corpus schema/version/missing-file or unsupported-native-integer failure is infrastructure-error. Case modes do not silently promote when such a check is unavailable. No theorem establishes native stack capacity, wall-clock performance, OS I/O cost or RSS; those need bounded real-process observations.
