## Implementation self-review

1. **Identity, signatures and scope.** Checked qualified/bare aliases, lexical placement, prior module/local initializers, the import destination depth limit, known bytes/text mismatches, and reuse of compiled arguments with flags. Rejected ambiguous bindings and expansions. Added a range selection precheck so excluded reference calls need no decoding.
2. **Grammar and consumption.** Compared group, reference, conditional, quantifier, comment and flag behavior to the two installed CPython parsers. Both parser sources differ only by an unused local. The iterative scanner verifies fixed-width lookbehinds and group availability before releasing edits. Closed a malformed empty global group, a dangling escape in a verbose comment, and a future set-difference case.
3. **Modes and equivalence.** Folded ASCII letter membership before comparing equivalent word-class spellings under IGNORECASE. Tracked whether captured content could contribute a case-fold difference, which removes the no-op root mutant for `(?i)(x)\1`. Replaced the broad Unicode lowercase/uppercase category test with a check for actual character case mappings.
4. **Cross-version character names.** Ruff uses Unicode 17, while CPython 3.14 uses 16. Compared the two installed Unicode databases and the pinned NameAliases data. The private compatibility check excludes the 47 newly assigned intervals, four new aliases and noncanonical leading-zero CJK escape spellings. Ordinary characters stay available as literals. Capturing-group identifier checks exclude newly introduced identifier characters.
5. **Decoded source mapping.** The mapper tracks escape spellings, raw/ordinary bytes and strings, physical continuations, token prefixes and delimiters. Crossing edits are decoded again against the intended changed pattern. Emptying an unspaced token can require a separator. Scoping an escape split after a raw backslash can leave an odd run before the closing quote. The mapper carries that scoped escape in the first token and retains the following token and comments.
6. **Cost and cancellation.** Bound referenced materialization independently per start/operator to K+1 descriptors, including K=0. The collector continues to consider competing positions/operators. Source decoding, grammar/long lexical units, bracket scanning and emission poll cancellation. A rejected sink returns before rendering a second reference variant. Separated parser operations, literal decoding and root-mode emission during review.
7. **Integration.** Compared actual default plans against plans excluding each individual ID and the remaining ordered descriptors. Restored the fixture's trusted import identity without weakening production safety checks. Verified user docs against generated CLI help and reused arbitrary saved verification commands.
