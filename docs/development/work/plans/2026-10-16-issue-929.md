# Issue 929: live analyzer diagnostic variants

Remove `UnreconstructableSpan`, `UnparseableReplacement`, and `InvalidRequest`
from the in-memory analyzer result type. The four current producer diagnostics,
plan/run strings, message and location conversion, and saved diagnostic strings
retain their behavior. No compatibility alias, schema migration, or new formal
model is needed. Baseline: `0d3fbc1a1821074d6ba8a2a212116241adc85c4e`;
branch: `refactor/issue-929-live-diagnostics`.

Consulted the analyzer concept, knowledge overview/index, test-structure concept,
development test guide, OKF workflow, Issue 929, and the Issue 865 record.
Historical records remain evidence about their original revisions.
