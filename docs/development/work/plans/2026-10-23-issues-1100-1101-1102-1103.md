# Agent-oriented output simplification implementation plan

> **For agentic workers:** Apply superpowers:dispatching-parallel-agents to the separate progress, review and telemetry domains; one coordinator owns shared CLI definitions, run/verify output and all builds/tests.

**Goal:** Remove four approved human-facing output features and deliver one PR closing #1100–#1103.

**Architecture:** Run/verify retain JSON and JSONL. Progress/review serialize their existing JSON documents directly with no format selector. Binary tracing uses JSON independently of TTY and retains its bounded asynchronous sink without periodic progress rendering.

**Tech Stack:** Rust 1.99, existing clap/serde/tracing, existing Python test/documentation environment.

**Spec:** User-approved four-row output-removal proposal and GitHub #1100, #1101, #1102, #1103.

## Global constraints

- Base origin/main 4af5591790106b4226167422013238b5d869dca6; dedicated branch/worktree names contain all four issue numbers.
- No backward compatibility aliases, old format acceptance, fallback or new dependencies.
- Preserve help, actionable errors, source safety, baseline/mutant logs, exit codes, history persistence, revision conflicts, saturation and detailed comparisons.
- Preserve JSON/JSONL schemas and structured contents; representation choices disappear only where one format remains.
- Keep terminal escaping for plain-text errors/help/stderr diagnostics; do not delete HumanText just because human report renderers disappear.
- One coordinator runs all Cargo commands with two build jobs, dev debug info off and incremental off. Shared root .venv is linked, not reinstalled. Test TMPDIR/TMP/TEMP are task-owned.
- Keep historical audits, goldens and formal proof materials; update current examples/reference and test harnesses.

## Review focus

- Deprecated run/verify human format and progress/review --format must fail before work begins.
- Progress/review without format arguments must return valid JSON; history/details/score/decision meanings stay intact.
- JSON and JSONL must keep failed baseline/mutant diagnostic content and finite write/flush handling.
- No terminal control injection through errors/help/remaining stderr diagnostics; JSON encoders preserve logical field values.
- Removing the periodic timer must not leave an idle diagnostics thread unjoinable or extend shutdown on blocked stderr.
