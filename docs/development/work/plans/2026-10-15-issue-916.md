# Issue 916: required persisted session budgets

## Design

New schema-5 databases require a positive eight-byte BLOB budget, including a
NOT NULL constraint. The existing reader validates values from databases created
with earlier schema-5 DDL, classifying NULL as session.corrupt just like invalid
types or lengths. Remove the special NULL compatibility branch. Do not change
selection queries, ownership acquisition, conditional updates or unsigned bytes.

Keep schema version 5 and release floor 0.8.0: normal stored values and tables
remain readable and writable in existing databases. Opening an existing current
DB must not rebuild its tables or repair data. Unsupported schema 1–4 behavior is
unchanged. Record the removal of the NULL-specific incompatibility diagnostic in
current guides; preserve historical migration records and golden fixtures.

The schema-5 golden DB has the previous nullable budget DDL and an incomplete
run with budget 100. Copy it into temporary directories to test both valid reuse
and corrupt NULL reading. This uses a real previous schema-5 artifact without
production migration helpers or disabling NOT NULL constraints. A separate
required-budget golden retains full semantic regeneration coverage of new DDL.

## Design self-review: five passes

1. Scope: two production edits express the existing writer invariant; no new
   generalized session state type, schema migration or compatibility adapter.
2. Reader: typeof(NULL) is not blob, so the current selection query already
   exposes a matching NULL row to validation; retain that corruption coverage.
3. Writer: NOT NULL and the existing positive fixed-width check protect separate
   conditions. Test NULL even when ignore_check_constraints is enabled.
4. Compatibility: verify existing valid nullable-DDL databases reopen and resume
   without schema rewrites. New constraints change no valid persisted values.
5. Costs: no additional queries, clones, table scans or schema introspection in
   production. Keep eligibility and ownership recheck exactly where they are.
