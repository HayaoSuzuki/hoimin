## Components and contracts

### Python analysis (#996, then #995)

Create an internal workspace crate `hoimin-python`. It owns the pure analyzer,
candidate payload leases, exception index and their private unit/oracle tests.
CLI retains filesystem reads, exception-project acquisition/fingerprinting,
processes and candidate spools. CLI, dedicated corpus/heap tests and fuzz use
the same Cargo API instead of source-importing private modules. Expose only the
existing requests, charged results, errors, budget/lease operations and index
operations required by these consumers. No multilanguage/plugin/public stable
API. Preserve the 16 MiB logical retained-payload budget and its exclusions.

Keep the separate fuzz workspace and its root-level parser patch; Cargo patch
resolution is workspace-root scoped. Remove redundant direct analyzer
dependencies where consumers no longer use them. Preserve dedicated allocation
tests and production performance gates when relocating private tests. Do not
add always-on metrics just to preserve a test; local private instrumentation or
explicit dev-only test support may preserve needed cross-boundary observations.

After extraction, visibility construction queries imported/loaded modules using
ordered exact/prefix lookup instead of all project mappings. Keep lexical
visibility, aliases, ambiguity, import roots, cancellation and the 65,536-entry
bound. Use operation counts and semantic outputs, never CI wall-time thresholds.

### Reports (#992)

One borrowed core identity projection and one hashing implementation own the
identity fields. The common current JSON/JSONL reader checks each candidate's ID
against this identity before comparing reports. Review consumes that guarantee
and retains its independent plan/source checks. No workspace access for
progress, no whole-config equality, and no extra display-field equality.
Arbitrary synthetic IDs cease to be accepted; update fixtures to real IDs.
Malformed identity returns exit 2 before regression/saturation output.

### Native filesystem names (#993)

Keep native OsStr/UTF-16 names as descriptor-relative I/O authority in the disk
meter; render a separate escaped/lossy diagnostic string. Account native-name
files, do not skip them. Preserve no-follow, mount/identity and meter bounds.
Linux invalid-byte and Windows accepted lone-surrogate tests are native-gated;
macOS/APFS cannot demonstrate Linux filesystem name acceptance.

### Copy admission (#994)

Carry the immutable configured copy cap into preflight inventory and streaming
checks. Check unique logical bytes times requested workers with checked
arithmetic before writing disallowed snapshot content. Copy equality succeeds;
owned-workspace equality continues to fail under the existing policy.
BudgetLedger remains the only mutable reservation/grant authority. Share
arithmetic rather than adding a second allowance ledger. Keep normal source
verification at two content passes. Preserve rollback/source growth handling.

### Selection and stopping (#998, then #997)

Construct execution selection and verification provenance once in core.
A checked selection request and private All/Explicit/Ordered state own
membership, ordered phase, explicit matched history and immutable provenance.
Validate mode, deduplicated count and Sample ID/order agreement at construction.
Use one owner for budget gating, scheduling, missing-ID handling and reporting.
Remove unrestricted later metadata attachment. Preserve the useful membership
index and requested-order vector and the Collecting/Ready phase.

Stopping derives a temporary borrowed ID-to-rank index from that owned order.
Keep stable requested-order merging and unordered sequence fallback. Do not
maintain a second persistent rank authority or use cached keys with linear
search. Cancellation/deadline/disk-stop, synthetic outcomes, late completions,
NotRun and exactly-once counts retain current semantics.
