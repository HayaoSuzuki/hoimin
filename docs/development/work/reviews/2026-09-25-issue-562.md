## Design pass 1 — runtime versus lexical semantics

Inspected the current AnnAssign branch and scope resolver. Finding: base already preserves ordinary imported names, but builtin tracking is an explicit exception; removing all annotation handling would break function locals. Remediation: design narrows the change to that exception and keeps function-local recording, including use before declaration.

## Design pass 2 — independent operator identity path

Traced ImportScan Store counting and unconditional import depth. Finding: updating only NameResolutionBuilder cannot restore operator aliases; statement nesting depth is not lexical scope. Remediation: design adds a separate current-function-scope flag with class reset and save/restore; retains depth for unconditional import eligibility.

## Design pass 3 — evaluation and evidence boundary

Finding: skipping whole AnnAssign loses executable target expressions; the existing corpus already has desired expectations but no strict adapter. Remediation: skip only bare no-value targets, preserve annotation visitation, and consume the generated corpus without editing expected values. Model correspondence remains a test claim, not a Rust proof.
