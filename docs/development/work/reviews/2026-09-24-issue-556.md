## Design review 1: source of unsound import facts

Confirmed with forwards only body fallthrough, while exception collection is
normally enabled by finally. Joining exceptions without enabling collection would
leave the original no-finally fixture broken. Design explicitly enables it locally.

## Design review 2: abrupt-exit classification

Read `visit_statement_flow`, `apply_finally`, and `route_finally_entry`. Found
explicit raise and return share `terminates`; merging this bucket would suppress
return. Added a distinct explicit-raise bucket and preserved the existing legacy
oracle projection contract. Finally overrides must replace pending raises.

## Design review 3: manager protocol boundaries

Traced ordered entry against nested-with semantics. First manager entry cannot be
self-suppressed, but its target binding and subsequent manager entry can be.
A blanket pre-with merge would wrongly remove the normal-import positive control.
Design now distinguishes these boundaries and inner exit failures.
