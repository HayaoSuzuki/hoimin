## Contract and implementation

The user approved removing four human-facing presentations from this CLI for
external AI agents. No compatibility reader, alias or fallback is added.

- Run and verify accept JSON and JSONL. The Human variants, report renderer and
  format-specific failure path are removed. Structured serializers and schemas
  are unchanged, including diagnostic routing and mutant evidence.
- Verify previews still return the same single JSON document in either retained
  output mode. The private rendering choice and human rows are removed; the
  preview writer takes only its destination.
- Progress always writes its existing schema-3 JSON document. Review always
  writes its existing schema-2 JSON document. Their format flags, selector enums
  and text renderers are removed, including `--format json`. Comparison/details,
  history, revision checks, counts and source validation stay in their owners.
- Binary diagnostics always use JSON tracing, independent of terminal detection.
  Snapshot/Update/ProgressLayer, periodic refresh and terminal rendering are
  removed. Existing opt-in stage tracing stays available through RUST_LOG.
- The diagnostics worker blocks on its receiver instead of a refresh timeout.
  Guard drop sets stop and tries to enqueue a wake-up record; an already-full
  queue guarantees an available record. Shutdown drains at most 128 records and
  waits at most 250 ms even if the sink blocks. The 64 KiB record limit and
  whole-record dropping policy are unchanged.
- HumanText remains for errors, clap context and progress warnings. Its now-unused
  quoted/transcript renderers are removed. JSON fields retain their logical
  strings and rely on serde escaping; help and plain errors still escape controls.

No dependency, lockfile, saved schema, candidate selection, outcome or exit-code
policy change is included. No new benchmark or formal proof execution is claimed.
Existing formal materials and historical records remain. Current command examples,
CLI reference and the improvement skill are updated for the smaller interface.

## Coverage migration

Tests for removed text spelling are deleted. Independent behaviors are retained
in structured assertions: reverse-order completion identity, actual parallel-run
full candidate IDs/verdicts, provenance, raw transcript values, hostile filenames
and diagnostics, dry-run side-effect absence, precise timeout values, review
revision/history, progress final-pair barriers and bounded comparison details.
Both JSON and JSONL schema/byte/spool/error tests remain. Memory-boundary tests
retain their allocation expectations; they no longer exercise a duplicate text
rendering pass.

The telemetry tests cover idle shutdown with a live publisher, queued draining,
a replenishing publisher that cannot extend the finite drain, blocked stderr,
and whole-record loss under queue/record pressure. Public CLI tests additionally
check quiet terminal stderr with logging off, JSON logs with logging enabled,
and existing blocked-sink execution deadlines. All eight telemetry integration
tests passed after updating the old heartbeat expectation.
