This bounded refactor starts from `30d158c7ead3252c5c0aa398e8ab1819ffa9d75b`
on `refactor/issue-959-unify-top`. The approved scope is representation cleanup;
no runtime selection defect was claimed.

`VerifySelection::Top { count, policy, offset }` represents every ranked request.
Rust callers constructing the former prefix form add `offset: 0`; callers of
`TopRange` use `Top`. No compatibility constructor or alias remains. CLI
normalization owns the omitted-offset default. The raw optional field retains
clap's explicit-offset constraints. Plan preparation and preview consume the
normalized value directly.

   offset without top, including an explicitly supplied zero.

   historical; its deterministic ordering and fixed-batch contract still apply.
   The original design, plan and review are preserved.

   repeated normalization without adding a helper or another public interface.
5. Compared selection, persistence and execution boundaries: ordering helpers,
   metadata constructors, saved schemas, candidate validation and dispatch need
   no behavior change. The existing Lean models remain applicable.
