# Issue 940: synthetic outcome ownership

Base: `465ff928c1f2ceb9f9b8f8084465475e45799ee8`. This refactor removes
representable invalid synthetic statuses and duplicated worker/action status.
The issue did not demonstrate an existing incorrect result count.

`SyntheticOutcome::Reused(ReusedMutationStatus) | NotRun` is private to the
machine. A worker owns it while output is pending; stop recovery moves it to a
`StoppedCandidate` and back to the drain worker. Output actions carry the worker
ID. The machine projects the owned outcome into report output and records its
status only after the finished-output ACK. Pending effect identity checks reject
retired and duplicate ACKs before they can access a replacement worker state.

`ResumeDecision::Reuse(ReusedMutationStatus)` changes the public Rust API and its
derived Serde representation: for example, `"Reuse"` becomes
`{"Reuse":"killed"}`. Callers must bind the status or match `Reuse(_)`. There is
no adapter. Repository searches found the machine, core policy tests, and CLI
session-handler tests as consumers, including the budget/resume Lean oracle's
boolean reuse projection. No report/session field serializes this enum. Report
schema 6 and session schema 5 remain unchanged. `StoredResult.status` still
accepts inconclusive and not-run results; policy returns `Rerun` for those values.

## Scope and design self-reviews

1. Traced the two existing owners through start, finish, ACK and stopped drain.
   The change removes action-owned status rather than adding a synchronization
   helper.
2. Checked stored-result producers and policy branches. Narrowing the stored
   schema would reject valid Timeout, OutOfMemory, ProcessLimit, Error and NotRun
   records, so narrowing occurs only when policy chooses reuse.
3. Searched Rust and formal consumers of `ResumeDecision`. Its public Serde
   derivation requires an API migration note even though report/session schemas
   do not change.
4. Read retirement and completion acceptance before changing ACK dispatch.
   Started and finished ACKs require the matching worker phase; stopped drain
   preserves the outcome and existing effect retirement.
5. Compared the bounded design with adjacent issues. Stop dispatch, global state
   fields, execution-result ownership and schema versions stay outside this
   change. The existing scheduler properties plus finite tables cover the new
   status/phase combinations without adding a second schedule model.

The current local design score is 8.75/10: seven of the eight
