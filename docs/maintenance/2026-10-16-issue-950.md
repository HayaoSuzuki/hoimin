## Design self-reviews

1. Construction: make_candidate already receives MutationOperator; no parser or
   new wrapper is needed at that boundary.
2. Identity: retain start/replacement/operator equality. HashSet requires adding
   Hash to the existing enum; BTreeSet needs no change of collection semantics.
3. Ranking: derived enum Ord is declaration order, unlike canonical lexical order.
   Both heap comparison and final stable sort must explicitly compare as_str().
4. Persistence: CandidateDescriptor and MutationCandidate retain strings; IDs,
   schema versions and serialization must remain unchanged.
5. Scope and evidence: direct includes compile the private module in integration
   tests and fuzzing. Existing Lean prefix correspondence suffices because no
   ranking or retention contract is intentionally changed.

Scoped design score: baseline 6.25/10 (five of eight rows supported), final
8.75/10 (seven rows supported). The design-investment percentage remains
unmeasured and earns no point. This assesses the candidate boundary, not the
whole analyzer architecture.

## Implementation self-reviews

1. Constructor and shared type now retain MutationOperator directly; no string
   parser, fallback or old String API remains in production.
2. Both dedup sets include the enum by value and the same start/replacement
   fields; Hash was derived on MutationOperator to preserve HashSet ownership.
3. Heap retains emission_sequence as its final key; final sort remains stable.
   Both operator comparisons use as_str(), never the enum-derived Ord.
4. Focused profile exemption uses the existing seven-element TYPE_OPERATORS
   array. CandidateDescriptor converts to its unchanged owned canonical string.
5. All direct include callers were inspected. The valid-Python and fuzz
   descriptors convert explicitly; shared tests and depth tests use canonical
   names for existing output expectations. The abstract Lean fixture's single
   arbitrary operator identity is explicitly projected onto CompareEqNe; no
   model, corpus, expected order, or production compatibility path was added.
